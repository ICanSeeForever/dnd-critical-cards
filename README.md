# D&D Critical Cards

Общая колода критических ударов и провалов для D&D. Все участники видят выбранную колоду и раскрытые карты в реальном времени. У каждой колоды своя история; карту также можно открыть по номеру без добавления в историю.

## Запуск

```sh
docker compose up -d --build
```

Сервис доступен на `http://127.0.0.1:18187/crits`. Данные истории хранятся в каталоге `data/`. Конфигурация `nginx-dnd.conf` содержит пример проксирования через Nginx; перед использованием её необходимо адаптировать к своему серверу и сертификату.

Исходные данные карт находятся в `cards.json`, изображения провалов — в `public/assets/`. Скрипты `extract.ps1` и `make-cards.mjs` позволяют обновить данные из исходных таблиц Excel; путь к папке таблиц задаётся параметром `Source` скрипта `extract.ps1`.

## Разработка

Для локального запуска нужен Node.js 22 или новее:

```sh
npm start
```

Приложение доступно на `http://localhost:3000/crits`. История сохраняется в `data/`, как и при запуске в Docker.

Для форматирования исходников используется Prettier с закреплённой версией:

```sh
npm ci
npm run format:check
npm run format
```

`format:check` проверяет оформление без изменения файлов; `format` применяет его. Данные карт, изображения и локальная история исключены из форматирования. Стили интерфейса собраны в `public/style.css`.

На экранах шириной до 700 px карты расположены сеткой без перекрытий, чтобы каждую можно было выбрать пальцем. На более широких экранах сохраняется веер. Раскрытая карта прокручивается внутри окна, если её содержимое не помещается по высоте.
